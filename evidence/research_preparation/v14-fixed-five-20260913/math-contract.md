## 1. 一期只有一个主要观察

令标签全集 U={1,…,49}，实际主号 Y_t 是一个六元素集合；特别号不参与本指标。五组 G_(t,1),…,G_(t,5) 各有六个不同标签，任意两组不相交；P_t 为其并集，|P_t|=30，池外有19个标签。

概率排序 r_1,…,r_49 降序，完全同概率时号码升序。令行号 a=0,…,5、列号 j=1,…,5：偶数 a 的第 j 列取 r_(5a+j)，奇数 a 取 r_(5a+6−j)。每列构成一组六个号码。五组和完整49号概率必须一起在揭晓前冻结；数学对照不输出额外实选组。

定义 H_(t,j)=|Y_t∩G_(t,j)|，M_t=max_j H_(t,j)。每期贡献一个 M_t∈{0,…,6}，不是五个独立开奖观察。定义 q_t=|Y_t∩P_t|=Σ_j H_(t,j)。主要指标永久固定为 M_t 的均值相对公平五组均值的差；不得用较好看的 Brier、q、单组、某一半区或 ≥k 指标替换。

## 2. 同结构公平主对照：精确单期分布

公平零假设 H0：给定全部开奖前信息 F_(t−1)，Y_t 在所有 N=C(49,6)=13,983,816 个六元素集合上均匀；冻结的五组是 F_(t−1) 可测的。无需假设组间命中独立；它们事实上受总抽取数六约束。

对 m=0,…,6，令 A_m(z)=Σ_(h=0)^m C(6,h) z^h，

    F_m = [z^6] (1+z)^19 A_m(z)^5，F_(−1)=0，
    w_m = F_m−F_(m−1)，Pr_H0(M_t=m | F_(t−1)) = w_m/N。

精确整数权重如下，不得拟合或用模拟替代：

|---:|---:|
| 0 | 27,132 |
| 1 | 5,093,064 |
| 2 | 7,564,500 |
| 3 | 1,230,100 |
| 4 | 67,725 |
| 5 | 1,290 |

Σw_m=N；Σm w_m=24,189,744；Σm²w_m=47,537,994。

    μ = E[M] = 24,189,744/N = 43,822/25,333
      = 1.7298385505072436。
    Var(M) = 24,039,506,739/59,042,001,788
           = 0.40715941213033047。

单期 Pr(M≥3)=1,299,120/N，Pr(M≥4)=69,020/N，Pr(M≥5)=1,295/N，Pr(M=6)=5/N。五个完整6/6事件互斥；不能把 5/N 改成五个独立事件的乘积公式。公平随机一组的均值36/49不适合作为主要五组对照。

实现这个数学计数的 DP：从多项式[1]开始，依次乘五次 [C(6,0),…,C(6,m)]，每次只保留0至6次项；再与[C(19,0),…,C(19,6)]卷积并取第6项。用非负任意精度整数。独立 oracle 逐个枚举五个计数 h_j∈{0,…,6} 且Σh_j≤6，以 Π_j C(6,h_j)·C(19,6−Σh_j) 累加到 max(h_j)，必须得到同一张表。此处枚举的是固定组合公式的计数状态，不是搜索号码、模型或参数。

## 3. 同一30号池的条件分组对照

给定当前冻结池与 q=q_t，均匀打乱池内30号再分成五组六号，等价于从五个固定大小为六的格子中均匀选择 q 个被实际命中的位置。其精确分布为：

    c_(q,m) = [z^q] A_m(z)^5 − [z^q] A_(m−1)(z)^5，
    Pr(M_pool_random=m | q) = c_(q,m)/C(30,q)，
    μ_q = Σm c_(q,m)/C(30,q)。

对 m=0，第二项按零处理。q=0时 c_(0,0)=1。完整权重表中各行顺序为 m=0,…,6：

| 1 | 30 | 0,30,0,0,0,0,0 | 1 |
| 2 | 435 | 0,360,75,0,0,0,0 | 34/29 |

检查 Σ_m c_(q,m)=C(30,q)，且 w_m=Σ_q c_(q,m)·C(19,6−q)。公平 H0 下 Pr(q)=C(30,q)C(19,6−q)/N。这一条件分布也直接描述“已固定实际号码和池后随机重排分组”的对照，无需实际生成随机组。

次要分组诊断固定为 d_t=M_t−μ_(q_t) 的均值，附全q直方图、每个q的观察数与 M 分布。q=0或1时 d_t 必为0。它区分覆盖集合与分组安排的贡献，不证明联合依赖，也不产生新的选组规则。

**不对整段已观察 q_1,…,q_n 序列直接乘条件概率作第二个显著性检验。** 后续池可以依赖先前开奖，因此未来q可能含先前M的信息；单期条件公式不自动证明给定整段q后独立。同池比较在本候选中只作描述，不分配额外显著性阈值。

## 4. 历史627期的固定期末精确检验

本稿的主要研究线路是预先固定的627期历史目标，固定分割为前314期和后313期。正式登记必须另行绑定完整有序目标日期和数据权威，不能在运行后选择日期。三种n的数学分布如下定义；**只有完整627期的检验是唯一主要判定**。两半的均值、区间和尾概率全部并列展示为次要诊断，不单独产生通过、选模或替代全期失败。

对固定 n∈{627,314,313}，T_n=Σ_t M_t。定义整数系数 D_(0,0)=1，其余为0，并逐期更新：

    D_(r+1,k) = Σ_(m=0)^6 w_m·D_(r,k−m)，r=0,…,n−1。
    Σ_k D_(n,k)=N^n，0≤k≤6n。

    numerator = Σ_(k=T)^(6n) D_(n,k)，denominator=N^n；
