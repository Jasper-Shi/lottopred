## Decision

The sole hypothesis considered here is:

> **H12:** In the current RNG regime, the odd-number count of the immediately
> preceding six-main-number set has a stable signed association with the
> odd-number count of the next six-main-number set.

**Decision: FREEZE-ELIGIBLE only as one narrow, research-only,
falsification-first V12 attempt.** The candidate is one lag-one conditional
exponential family, with one signed coefficient, one `N(0,1)` prior, one exact
fair distribution, and one fixed pseudo-parity sanity control. It is not a
search over parity rules.

The prior probability of a real signal is low. The reviewed official sources
define a random six-of-49 draw, describe draws as independent events, and
describe independently tested RNG software. None of the reviewed official
materials discloses an odd/even bucket, a cross-draw state carried into the
next draw, or the production scaling/mapping code. V12 can therefore test only
for serial dependence in the **published final six-main-number sets**. It may
not be described as evidence about an internal RNG state, entropy source,
call order, raw-output parity, or mapping defect.

This note is not an experiment registration and authorizes no scoring. A later
pre-registration must freeze the exact data object, commits, config, source
identity, implementation paths, runtime, artifacts, and notification behavior

```text
(134596, 1062600, 3187800, 4655200, 3491400, 1275120, 177100)
```


The standardised state used by V12 is fixed from theory, not estimated:


## Sole candidate law

### Strict-prefix transition rows

For a target draw date `t`, take the verified post-RNG main draws strictly
before `t`, in increasing date order:

```text
D_0, D_1, ..., D_(n-1),  with draw_date(D_0) >= 2019-05-15.
```

Every eligible training row is one consecutive transition whose destination
is also strictly before `t`:

```text
x_j = x(D_(j-1))
k_j = K(D_j),                         j = 1,...,n-1.
```

The target uses `x_prev=x(D_(n-1))`. The transition ending at the target is not
a training row until after its prediction has been durably frozen, the target
has been revealed and scored, and a later target is forecast. Bonus numbers,
pre-RNG draws, the target row, and every future row are excluded.

### Conditional exponential tilt

For one signed scalar `beta`, set `eta=beta*x_prev` and define

```text
Z(eta) = sum[k=0..6] N_k exp(eta k)

P_beta(K_target=k | x_prev)
    = N_k exp(eta k) / Z(eta)

P_beta(S_target=S | x_prev)
    = exp(eta K(S)) / Z(eta),          for every |S|=6.
```

The complete-set formula is normalized because there are exactly `N_k` sets
in bucket `k`. At `beta=0`, it is exactly the uniform law `1/C(49,6)`.
There is no intercept, second lag, nonlinear state, fitted centre/scale,
temperature, V1 blend, or hard parity constraint.

Let

```text
M(eta) = sum[k=0..6] k N_k exp(eta k) / Z(eta).
```

Exchangeability within the two fixed parity classes gives all 49 inclusion
marginals without an independent-cell fiction:

```text
p_i = M(eta)/25                 if i is odd
p_i = (6-M(eta))/24             if i is even.
```

Every probability must be finite and strictly in `(0,1)`, the keys must be
exactly `1..49`, and `abs(math.fsum(p_i)-6.0) <= 1e-12`. No clipping,
renormalization, imputation, or probability repair is permitted.

### One `N(0,1)` MAP coefficient

The prior is exactly `beta ~ N(0,1)`. Constants independent of `beta` are
omitted from the log posterior:

```text
L_t(beta) = -beta^2/2
            + sum[j=1..n-1] (beta x_j k_j - log Z(beta x_j)).

U_t(beta) = dL_t/dbeta
          = -beta
            + sum[j=1..n-1] x_j (k_j - M(beta x_j)).
```

The derivative of `U_t` is

```text
U_t'(beta) = -1 - sum[j=1..n-1] x_j^2 Var_beta(K | x_j) < 0.
```

Thus the score has one and only one root. The coefficient is signed: positive
`beta` represents parity-state persistence and negative `beta` represents
alternation/mean reversion. Neither sign may be selected after results are
known.

## Frozen stable binary64 evaluation

For any finite `eta`, evaluate the tilted moment in ascending `k` order:

```text
a_k  = eta * float(k)
amax = max(a_0,...,a_6)
w_k  = float(N_k) * exp(a_k-amax)
D    = math.fsum(w_k for k=0,...,6)
M    = math.fsum(float(k)*w_k for k=0,...,6) / D
logZ = amax + log(D)
```

The mandatory implementation oracles are

```text
M(1.0)    = 4.319084357868955
          = 0x1.146be0cc6d96bp+2
logZ(1.0) = 20.163592827882024
          = 0x1.429e138359d0bp+4.
```

Compute the score as one ordered sum:

```text
U(beta) = math.fsum([
    -beta,
    *[x_source*(K_destination-M(beta*x_source))
      in ascending destination-date order],
])
```

If there are no transition rows, or if `U(+0.0) == 0.0`, return the canonical
binary64 value `+0.0`. Otherwise set

```text
B  = 1.0 + 6.0*math.fsum(
         abs(x_source) in ascending destination-date order)
lo = -B
hi = +B.
```

Because `0 <= K,M <= 6`, `U(-B)>0` and `U(B)<0`; this is a strict bracket. Run
exactly 256 iterations with no early stop:

```text
mid = lo + (hi-lo)/2.0
if U(mid) > 0.0:
    lo = mid
else:
    hi = mid                 # equality goes to the upper endpoint

beta = lo + (hi-lo)/2.0
```

Newton steps, library optimizers, tolerance-based termination, coefficient
clipping, alternate brackets, and post-solver repair are prohibited. One-row
training with `(K_source,K_destination)=(6,6)` must produce

```text
B    = 16.21419166130678 = 0x1.036d543c46377p+4
beta = 1.0755457921281115 = 0x1.1356f8128a684p+0.
```

When `beta == +0.0`, bypass the tilted calculation and assign every label the
bit-identical literal `6.0/49.0`; assign the joint log gain `+0.0` directly.
This exact-fair bypass prevents harmless round-off from fabricating a ranking
or likelihood difference.

## Ranking degeneracy is part of the hypothesis

Rank all labels by descending probability and then ascending numeric label.
Top-6, Top-12, and Top-18 are prefixes of that one ranking; Final-6 is the
sorted Top-6. V12 may not add a V1 tie-break or combination optimizer.

The candidate has only two marginal values, so its ranking is deliberately
degenerate:

| Target `eta` | Higher class | Top-12 | Final-6 |
|---|---|---|---|
| `eta > 0` | all odds, tied | `1,3,5,...,23` | `1,3,5,7,9,11` |
| `eta < 0` | all evens, tied | `2,4,6,...,24` | `2,4,6,8,10,12` |
| exact-fair bypass | all 49 tied | `1,2,...,12` | `1,2,3,4,5,6` |

For nonzero `eta`, all 25 members of one parity class precede all 24 members of
the other. Therefore the magnitude of `beta` changes proper scores and the
complete-set likelihood, but the Top-K ranking changes only with the sign of
`eta`. This severe loss of within-class resolution is a required limitation,
not something that may be repaired after observing scores.

## Interpretation

V12 is mathematically coherent because its fair bucket law is exact, its
one-parameter conditional set distribution is normalized, its 49 marginals
follow by parity exchangeability, and its prequential joint gain has an exact
fair-null interpretation. It is also intentionally weak as a number-ranking
model: within each parity class every label ties, so almost all ranking
information collapses to one sign.

No reviewed primary source supplies a parity-transition mechanism. The correct
default is that `beta=0`, the candidate converges to `6/49`, controls behave as
nulls, and V12 is rejected. A nonzero historical estimate is not evidence of a
mechanical flaw; only an unchanged prospective cohort clearing every frozen
gate could justify further review.
